Scripart 개인정보처리방침

시행일: 2026년 11월 17일

Scripart(이하 "앱")는 녹음, 전사, 요약, 노트를 모두 사용자의 기기 안에서 처리합니다. 앱 개발자는 사용자의 녹음이나 글을 받거나 보관하지 않으며, 회원 가입도 받지 않습니다.

1. 수집하는 개인정보

앱 개발자가 수집하는 개인정보는 없습니다. 앱에는 광고, 사용 통계 수집, 오류 보고 기능이 없습니다.

2. 기기 안에서만 처리하는 정보

다음 정보는 사용자의 기기에만 저장되며 앱 개발자나 다른 서버로 보내지 않습니다.

  • 녹음한 음성과 사용자가 불러온 음성·영상 파일
  • 전사한 글, 요약, 할 일, 노트, 메모, 사진
  • 용어 사전, 설정

음성 파일은 AES-256-GCM으로 암호화해 저장하고, 암호화 키는 운영체제의 보안 저장소 또는 앱 데이터 폴더에 둡니다.

3. 기기의 권한

  • 마이크: 녹음할 때만 씁니다.
  • PC 소리 녹음(macOS·Windows): 사용자가 PC 소리 녹음을 고를 때만 씁니다.
  • 카메라·사진: 노트에 사진을 넣을 때만 씁니다.
  • 생체 인증(Face ID, Touch ID, 지문 등): 앱 잠금을 켰을 때 운영체제가 확인하며, 앱은 결과(성공 여부)만 받습니다.
  • 캘린더: 사용자가 할 일을 캘린더에 추가할 때 운영체제의 일정 추가 화면을 엽니다.

4. 인터넷을 쓰는 경우

  • AI 모델 내려받기: 앱에 들어 있지 않은 AI 모델을 처음 쓸 때 Hugging Face 등 모델 배포 서버에서 모델 파일을 내려받습니다. 이때 사용자의 녹음이나 글은 보내지 않으며, 일반적인 인터넷 연결처럼 서버가 접속 IP 주소 등을 볼 수 있습니다.

5. 사용자가 직접 내보내는 경우

다음은 사용자가 직접 고른 경우에만 일어나며, 보낸 뒤에는 받는 쪽의 정책을 따릅니다.

  • 공유·내보내기: 사용자가 고른 앱이나 위치로 문서(PDF, Word, 한글, Markdown, 텍스트)나 음성 파일을 보냅니다.
  • 기기 간 동기화: 사용자가 고른 폴더(예: iCloud Drive, Google Drive, OneDrive 폴더)에 기록을 저장합니다. 기록은 사용자가 정한 동기화 암호로 암호화한 뒤 저장하므로, 그 폴더를 제공하는 회사도 내용을 읽을 수 없습니다.

6. 보관과 삭제

정보는 사용자가 지우거나 앱을 삭제할 때까지 기기에 남습니다. 앱에서 기록을 지우면 그 음성과 글이 함께 지워집니다. 앱을 삭제하면 기기에 저장된 앱 데이터가 지워집니다. 동기화 폴더에 저장한 사본은 사용자가 그 폴더에서 직접 지워야 합니다.

7. 아동

앱은 아동의 개인정보를 따로 수집하지 않습니다. 앱 개발자는 어떤 사용자의 개인정보도 받지 않습니다.

8. 방침의 변경

이 방침이 바뀌면 앱 업데이트와 함께 알리고, 시행일을 고칩니다.

9. 문의

개인정보에 관한 문의는 App Store, Google Play, Microsoft Store의 Scripart 페이지에 있는 개발자 연락처로 보내 주세요.
